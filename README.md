# Security Toolkit

Here you can find some tools that can be useful if you are starting in cybersecurity or if you want to protect more your online life. 
The tools will help you check how strong your passwords are and analyzing the port on your computer. 

## Vision and goals

This project exists to document my learning in cybersecurity and to serve as a portfolio of my skills. 
I use it to experiment with new tools and techniques as I improve. I'm here to learn and to share what I have learned.

## Tools available

### Port Scanner
Scans a range of TCP ports on a given IP or hostname and reports which ones are open.
[Port Scanner](port_scanner/README.md)

### Password Checker
This tool allow you to test how strong are your passwords and help you to find stronger passwords for protecting your online account.
[Password Checker](password_checker/README.md)

### Password Generator
This tool allow you to create strong passwords with multiple characters for protecting your online account.
[Password Generator](password_generator/README.md)
