# Security Toolkit

Here you can find tools useful for anyone starting in cybersecurity or looking to better protect their online accounts. These tools help you check how strong your passwords are and scan open ports on a target host. 

## Vision and goals

This project exists to document my learning in cybersecurity and to serve as a portfolio of my skills. I use it to experiment with new tools and techniques as I improve. I'm here to learn and to share what I have learned.

## Tools available

### Port Scanner
### Port Scanner
Scans a range of TCP ports on a given IP or hostname and reports which ones are open.
[Port Scanner](port_scanner/README.md)

### Password Checker
This tool allow you to test how strong are your passwords and help you to find stronger passwords for protecting your online account.
[Password Checker](password_checker/README.md)
